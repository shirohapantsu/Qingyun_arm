## 2. 实现说明（文件 + 关键符号）

### 2.1 新增 `scripts/fit_grade_threshold.py`

- CLI：`--input CSV --output 建议K文件 --report PATH`（§3.1 惯例）+ 显式
  `--policy midpoint|a_min`。退出码 `EXIT_OK=0` / `EXIT_INPUT=2`（缺文件/坏
  CSV/坏数值/重复 ID/C 或其他标签/空组；argparse 缺参/未知参同为非零）/
  `EXIT_NO_PROPOSAL=3`（两组面积重叠）；`EXIT_NOT_ACCEPTABLE=4` 为 acceptance 结
  论块专用。
- 输入 schema 常量 `CSV_COLUMNS = ("sample_id","grade_label","length_m","width_m")`
  在 --help 与报告三处固化为同一常量；表头逐字校验（缺/多/改名拒绝）。
- `load_grade_samples`：grade 严格 A/B（C/未成熟标签拒绝并附 `C_REJECTION_NOTE`
  「不成熟由 classify 判 C、与面积无关」）；数值有限、`width>0`、`length>=width`
  （P1 §6.4 同式）；`sample_id` 非空唯一；A/B 任一空组拒绝；逐行收集全部问题后统
  一拒绝（不静默剔除，分母=全部样本）。
- `GradeSample.area_m2` 与 `classify_area(area, k) -> "A" if area >= k else "B"` 与
  P1 §3.5 逐字同式（等号归 A）。
- `fit_grade_threshold(samples, policy)`（纯函数）：`a_min = min(area|A)`、
  `b_max = max(area|B)`；**当且仅当 `a_min > b_max`** 才建议；不变量
  `b_max < K <= a_min`（K==b_max 会把 B 边界判成 A——绝不允许；K==a_min 等号归 A
  合法）。策略：
  - `midpoint`（默认）：`K=(b_max+a_min)/2`，两侧余量均正；若两组浮点相邻导致中点
    舍入并入 b_max，如实上调为 `a_min` 并记 `policy_adjustment`；
  - `a_min`：`K=a_min`，A 组最小样本恰好 `area==K` 判 A（「边界样本归 A 验证」的
    最直白形态），A 侧余量 0、B 侧余量最大。
  成功前再断言 K 有限正数并 `verify_against_samples` 逐样本回代（人工标签 vs
  classify 全一致，否则拒绝）。
- 输出：`--output` 建议 K 文件（JSON：`area_threshold_m2`、policy、a_min/b_max、
  `margin_a_m2/margin_b_m2`、`input_sha256`、`boundary_semantics`、`backfill_target
  =qingyun/plans/strawberry.py::AREA_THRESHOLD_M2`、`backfill_notice`）；
  `--report` JSON 报告（输入 SHA256、`input_schema`、样本数与逐样本分母、两组面积
  分位数 min/p05/p25/p50/p75/p95/max 散布、fit 结果与拒绝理由、`notes` 五条职责/
  来源/回归注记、`overall_pass`）。重叠拒绝时**只写报告、不写建议文件**、退出 3。
  工具全程只写 output/report 两文件，**绝不写 plans 代码**。
- demo_acceptance 共用 loader（同文件内，理由见 §7 自主决策 1）：
  `DEMO_ACCEPTANCE_KEYS`（§3.1 五键逐字）+ 可选键 `source ∈ {measured,simulated}`
  （缺省 measured）；`validate_demo_acceptance`：未知键/缺键拒绝、
  `schema_version` 必须严格整数 1、bool 一律非法、ratio>1、rate∈[0,1]、不确定度
  有限非负；`load_demo_acceptance(path)`；`evaluate_demo_acceptance(path_or_data)`
  返回 `verdict ∈ {acceptable, incomplete_not_acceptable}` + `exit_code`（0/4）——
  含 null 时**永远给不出 acceptable**；simulated 名义值可解析且 `verdict_text`
  如实标注「不得冒充实测」。

## 5. 问题与限制

- **A/B 类边界**：本工具是纯 A 类数值工具——样本 CSV 的尺寸与人工标签是 B 类证据
  （队友/用户交付），工具不生成、不替代、不自动打标；未提供实测前 `AREA_THRESHOLD_M2`
  保持 None 与生产拒绝语义不变（P1 §3.2 第 3 条）。
- 拟合只保证「与人工标签自洽的分界存在」，不评价人工定级本身的正确性——定级口径
  争议须回到 §3 人工流程复核，报告的分位数/散布数据即为此准备。
- 两组浮点相邻（差 <1 ulp）时 midpoint 会退化为 `a_min` 并注明；这属于 B 类样本
  区分度不足的信号，报告理由文本会提示人工复核，而非工具自行外推。
- CSV 全量拒绝策略意味着一行坏数据即整体退出——对人工整理后的样本表这是可接受且
  更可审计的行为（静默剔除才会污染分母）。
- loader 的 `source` 键是本实现为 §3.1「明确标注 source=simulated」提供的落点：
  模板五键本身保持逐字不变（模板文件里没有该键），仅加载器接受这个可选标注键。

## 7. 自主决策

1. **共用 loader 放在 `scripts/fit_grade_threshold.py` 内**（任务书允许「放 scripts/
   内部函数即可或 configs/demo_acceptance.py——选择改动最小处」）：修改范围清单不含
   新文件 `configs/demo_acceptance.py`，放本脚本内改动最小；后续任务可原样平移为
   独立模块，函数签名不含拟合工具的任何状态。
2. **K 默认策略取 `midpoint`、`a_min` 为显式可选项**：midpoint 两侧余量均为正、对
   测量末位舍入最稳，且 `area==K` 判 A 在两组内都不触发等号——作为默认；`a_min` 策
   略把分界压到 A 组下界，「边界样本归 A 验证」恰好是规格给出的合法形态（等号归
   A），保留为显式策略并把两侧余量写进报告。依据 §2.4「A 下界与 B 上界之间的保守
   分界」两种读法都覆盖，评审可凭报告余量改选。
3. **不变量 `b_max < K <= a_min`（而非 `>=`）**：classify 等号归 A，故 K 等于 a_min
   合法、等于 b_max 非法（会把人工 B 边界判成 A）；midpoint 浮点相邻时上调到
   a_min 是唯一保序做法。另加 `verify_against_samples` 逐样本回代作最终闸。
4. **可选 `source ∈ {measured,simulated}` 键**：§3.1 既要求「未知键拒绝」的严格
   schema，又要求独立模拟配置「明确标注 source=simulated」；模板文件五键逐字不动，
   由加载器额外接受这一个可选标注键（拼错的 soucrce 仍按未知键拒绝），缺省
   measured。名义值即使 complete 也在 verdict_text 中如实声明「不得冒充实测」。
5. **退出码分层 0/2/3（+acceptance 的 4）**：沿用 P4-03/P4-04 已确立的仓库惯例
   （输入级 2、判据级 3）；「不完整、不可验收」用独立码 4 与 K 工具的 3（重叠）区
   分，消费工具可直接透传。
6. **报告恒含全样本分母与逐样本明细**：对齐 §3.1「报告保留输入 schema、每条失败
   与全部样本分母」——重叠拒绝时分位数/散布即复核材料；坏行拒绝时 stderr 汇总前
   20 条并计数。
7. **测试用 `type("PlanWithK", (StrawberryPlan,), {...})` + `FakeArm()` 走真实
   classify**（任务书「MockStrawberryPlan 覆盖 K 或真实 plans」择一）：monkeypatch
   类属性会随 fixture 恢复、但显式子类更直观地钉住「生产 StrawberryPlan.AREA_THRESHOLD_M2
   仍为 None + 工具没写 plans」两条断言。
