## 1. 任务与依据

按 P4 §2.5 交付**落点标定工具**：把示教的 **TCP 释放位姿**换算为**物体中心 `PlacePose`**，
按 §2.5 判据校验，产出 **draft 候选 places**（通过前不覆盖已发布 profile），并配 P4-T03
合成测试。**测试范围指示（用户 2026-09-23）：P4 阶段只做定向测试，不跑全量。**

规格依据（逐条对齐）：

- P4 §2.5：输入=示教记录（复用 `read_workcell_waypoint.py` 读反馈的做法）；功能=TCP 释放
  位姿换算物体中心 `PlacePose`（position=释放时物体中心、yaw=物体长轴角），写入 `places`
  的 `strawberry_A_01..N`（有序）、`strawberry_B_bin`、`strawberry_C_bin`；判据=先生成 draft
  候选再验证、通过前不覆盖已发布 profile；`default`/`bin` 旧条目不得自动充当新 ID；A 槽位
  按各自 yaw 构造 envelope 水平矩形、逐对净距 ≥ `collision.clearance_m`、二维检查不得用标量
  代替；B/C 只做形状与 ROI 外检查，箱口开度/释放高度/撤回路线=现场 B 类。
- P4 §3.1：纯输入输出工具最小 CLI 惯例 `--input --output --report`（本工具另加 `--profile`）；
  未知/缺参退出码非 0。§4 P4-T03：TCP→物体中心换算与运动文档 §3.4 逆变换一致。
- 机械臂运动控制模块技术文档 §3.3/§3.4：抓取 spin = 物体 yaw + `grasp.yaw_offset_deg`；
  `T_TCP_O = inv(FK_TCP(q_close,g_close)) @ T_B_O_grasp`；`T_B_TCP_place = T_B_O_place @ inv(T_TCP_O)`。
  **配置 `places.position` 是"释放时物体中心"而非 TCP**，故换算必须走该刚体关系，不能直接把
  配置里的物体中心当 TCP。
- `qingyun/grabbing/kinematics_ext.py`：`holding_transform` / `object_pose` / `place_tcp_pose` /
  `top_down_pose` / `ArmModel.fk_tcp` 的**既有正向语义**——逆变换工具复用同一套函数，不另推公式。
- P3 §6.4：二维净距公式 `r=(L|dot(long,u)|+W|dot(short,u)|)/2`，`d=dist-ri-rj`；与视觉邻距/
  `target_bounds` 闭区间同源；`safety.object_box` 用 `rz_deg(yaw)` 定义长/短轴，与之一致。

## 2. 实现说明（文件 + 关键符号）

### 2.1 新增 `scripts/calibrate_place_poses.py`

- CLI：`--profile --input --output --report`（argparse，`--input/--output/--report` 对齐 §3.1）。
  退出码 `EXIT_OK=0` / `EXIT_INPUT=2`（连接/输入级：坏 profile、缺/坏输入、未知 place、
  记录字段非法、`--output` 命中输入 profile）/ `EXIT_CRITERIA=3`（§2.5 判据不通过）。
  缺/未知 CLI 参数由 argparse 以非零码 + 用法信息退出（P4-T06 惯例）。本工具是纯运动几何、
  **不连接驱动、不触碰 vision**，故 §3.1"运动脚本连接前确认"那一支不适用（已如实注明）。
- `_ModelBox`：延迟构造 `ArmModel`——仅 `mode=joints`（关节角读回→FK）才付 placo/URDF 成本；
  `mode=tcp`（自报）全程零 placo。
- `resolve_tcp_pose(spec, params, model_box, where)`：`mode=tcp → K.top_down_pose(xyz, yaw)`；
  `mode=joints → ArmModel.fk_tcp(q, gripper_pct)`（闭爪保持开度，技术文档 3.3/5.3）。
- `resolve_holding`：`T_B_O_grasp = object_pose(grasp_object_center_m, grasp_object_yaw_deg)`；
  `T_TCP_O = holding_transform(T_B_TCP_close, T_B_O_grasp)`（§3.4）。meta 记录 method/
  yaw_offset_applied 等，供报告 B 类证据说明。
- `tcp_to_object_place(T_B_TCP_release, T_TCP_O)`：**§3.4 正向的逆**
  `T_B_O_place = T_B_TCP_release @ T_TCP_O`；position=T[:3,3]，yaw=wrap180(atan2(R10,R00))。
- `closure_residual_m`：用运动模块同款正向 `place_tcp_pose(object_pose(pos,yaw), T_TCP_O)` 复算回
  TCP 与示教释放 TCP 的逐元素最大差（顶抓一致≈0；残差=示教姿态的额外倾角）。
- 判据几何：`inside_closed_bounds`（逐轴闭区间，与视觉过滤同一区间语义）；`net_distance_2d`
  （P3 §6.4 二维净距，中心重合→ -inf 判不足）；`classify_place`（`strawberry_A_<NN>`→('A',序)，
  `strawberry_B_bin`/`strawberry_C_bin`→'B'/'C'，其余 `InputError`）。
- `evaluate`：换算每条 trial + 判据 c/a/b/d/e 逐项结果，返回结构化结果与 `overall_pass`；
  不写文件、不以异常传播判据失败。`build_candidate_profile`：在**深拷贝**上替换/新增
  strawberry_*（A 按序号有序），保留 `default`/`bin` 等旧条目原样，候选恒为
  `status=draft`、`verification=null`。`build_report`：资源哈希、每条换算前后与闭合残差、
  A 槽逐对净距、判据逐项、待实测清单、`overall_pass`。
- 交付规则钉死：`run()` 仅在 `overall_pass` 时写 `--output`；否则只写 `--report` 并返回 3。
  `--output` 若解析到 `--profile` 直接 `InputError`（禁改写输入源）。工具全程只写 output/report，
  绝不写 profile/输入记录。

## 5. 问题与限制

- **本工具不产生 B 类证据**：箱口开度、释放高度、撤回路线、逐点一次释放验证、A 槽清空前提
  ——全部在报告里以"待实测（现场）"列出，绝不伪造通过（判据 e 不设伪门槛，其形状/有限/ROI
  外若失败已在 a/c 记为不过）。
- **物体中心来自持物关系的刚体传播**，前提是夹持期间不发生超过标定误差界的滑移（§3.4）。若示教
  姿态带额外倾角（q_close 非严格顶抓），`closure_residual_m` 反映该偏差；报告如实记，不作为判据
  门槛（§2.5 未规定闭合残差门槛）。
- **yaw 的 ±180 不定向性**：config `PlacePose` 按 §3.2 存 wrap180 长轴角。当示教释放方位角落在
  (90,180] 归一化到 [-90,90) 时，`object_pose(pos,yaw)` 复算的 TCP 可能与示教释放 TCP 相差 rz(180)
  ——这与运动模块消费 `PlacePose` 的方式完全一致（同闭区间/同归一），不是换算错误；P4-T03 双向
  闭合用例特意选**内部 yaw** 精确复算，wrap 边界用例只校验归一化与范围、不主张 full-orient 闭合。
- 未跑全量（遵定向指示）；本工具不 import `main`/`vision`，`kinematics_ext` 只在 joints 模式经
  `ArmModel` 触达 placo。

   与 `read_workcell_waypoint.py`"读反馈示教记录"精神一致且离线可测。
5. **二维净距按 P3 §6.4 原式实现**（长/短轴用 `rz_deg(yaw)`，与 `safety.object_box` 同定义），
   中心重合返回 -inf 判不足，闭区间 `d==clearance` 判通过——与视觉邻距判据口径同源。

   A 槽逐对净距、判据逐项、待实测清单。
