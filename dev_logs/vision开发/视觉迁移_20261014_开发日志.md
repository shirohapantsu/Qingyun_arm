## 3. 接口冲突与修正

### 本地契约优先

- 公开函数签名、异常名称和兄弟关系不变；调用方 main/plans 不改。
- 旧 `grade` 三字段接口改为六字段：`position/yaw_deg/length_m/width_m/ripe/valid_count`。Plan 继续承担品级/放置选择；视觉仅输出几何和成熟度。
- position 为 base_link 米制 float64，yaw 为基座无向长轴 `[-90,90)`；不再返回相机毫米坐标、固定 yaw 或图像框尺寸。
- 导入入口无相机/模型/OpenCV 副作用；configure 保存阈值深拷贝，init 才加载重依赖。
- 路径相对具体 vision JSON 的所在目录解析，移除开发机绝对路径与固定 configs 根。
- 生命周期重复调用、非法 ignore（包括 bool）、资源和设备故障均为硬错误；无目标/全过滤/跳尽/耗尽为明确 NoTarget 原因。

### 管线与审计

- 原始轴向深度按 depth_unit_m 转为 m；深度去畸变、D2C 投影、最近 RGB Z 优先，空洞不填伪深度。
- 根据 OBB 全区域/内区域的深度连续分量测量 base XY 长轴、短轴和 yaw，剔除桌面；几何中心 Z 采用半高模型。
- 低置信度、未映射/超尺寸等被过滤邻物仍参与足迹净距；无法建立邻物几何时保守拒绝其他候选。
- 检查 XYZ 工作域、两维尺寸、可见头顶占用与净距。排名键完整使用 clearance、ROI 距离、x/y/z；valid_count 为过滤后数量，position 返回副本。
- 每次 get_target 写一条 vision_scan，包含源帧、时间、候选/拒绝原因、合法数量、选中目标；孤立目标的无限净距以 null + isolated 存日志，避免非法 Infinity。
- 支持 fixture/replay 与 RKNN/OpenNI；也支持 .pt YOLO-OBB。保留原 `yolo` + `.rknn` 配置兼容，但默认模板明确 rknn。NPU 低 detection_floor 上保留邻物，并撤销中心 crop/输入 resize。

### 标定与采集

- 原分支内参为 1280×1024 深度模型，D2C 平移仍为 mm；原恒等外参也是占位。两者留在 reference，运行模板保留未测 null，不宣称可驱动生产。
- touch 标定拒绝点数不足、共线/重合、NaN/Inf；拟合残差 >4mm 不保存。默认保存候选外参，不覆盖生产文件；拟合点残差不冒充独立 CAL-040 验收。
- 使用真实 `openni==2.3.0` Python 绑定源码核对 API：wait_for_any_stream 的 timeout 是秒，内部转换至 ms，超时返回 None。已修正原代码的秒/毫秒混用，并禁止超时后继续 read_frame；对应模拟 SDK 回归通过。诊断脚本同样修正。
- 新增 opencv-contrib-python（含 ArUco）测试依赖；附加 RKNN/OpenNI/YOLO 部署依赖单独说明。没有安装 udev 规则，没有连接或驱动硬件。
