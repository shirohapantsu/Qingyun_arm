# SO-ARM101 抓取—放置参数测量与标定指南

> 配套：[运动控制](机械臂运动控制模块技术文档.md)、[姿态数学](顶抓姿态构造与R_top_down标定.md)、[公共接口](../configs/common_interface.py)。本文规定配置字段、测量步骤、计算公式、标定工具及验收方法。
> `motion_params.py` 与 `scripts/calibrate.py` 按本指南实现；文中的 CLI 是待实现接口。物理未知值保留为 null，实机运行前完成测量与验收。

## 1. 配置与标定工具

### 1.1 标定包

```text
calibration/<robot_id>/<profile_id>/
  profile.json                 # 运行期参数与 places 放置位姿
  motor_calibration.json       # 官方电机校准数据
  raw/*.jsonl                  # 原始读数、参考测量与实验记录
  reports/validation.json      # 参数验收结果、输入哈希及人工实物评估
```

`MotionParams` 的嵌套属性与 profile.json 字段逐项同名，数组加载为 np.float64；`places` 映射的每个值加载为公共接口 PlacePose。相对路径以 profile.json 所在目录为基准。

```python
def load_motion_params(profile_path: Path, *, mode: Literal["real", "mock"]) -> MotionParams: ...
```

real 模式要求 status=verified、全部运行期字段非 null，模型和电机校准文件哈希与验收报告匹配；mock 模式使用独立 status=simulation 配置。加载时拒绝未知键、缺失键、非有限值、错误 shape、非法旋转、空限位交集和不单调标定表。

放置位置与角度全部保存在 `places`。下面仅演示 JSON 结构，null 必须由测量结果替换：

```json
{
  "places": {
    "default": {
      "position": [null, null, null],
      "yaw_deg": null
    }
  }
}
```

position 是释放时的物体中心，单位 m；yaw_deg 是该物体长轴相对基座 +X 的角度，范围 `[-90,90)`。place_id 是映射键；不在控制模块内根据品级解释它。

### 1.2 标定 CLI

```text
python scripts/calibrate.py init --output <目录> --robot-id <ID> --profile-id <ID>
python scripts/calibrate.py capture --stage <阶段> --profile <文件> --output <数据.jsonl> [--hardware]
python scripts/calibrate.py fit --stage <阶段> --profile <文件> --input <数据.jsonl> --output <候选配置.json>
python scripts/calibrate.py validate --stage <阶段|all> --profile <候选配置.json> --input <验证数据.jsonl> --report <报告.json>
python scripts/calibrate.py promote --profile <候选配置.json> --report <报告.json> --output <配置.json>
```

阶段固定为 `motor / joints / tool / workcell / timing / motion / grasp / pick_place`。capture 未给 --hardware 时使用模拟源；硬件采集按第 3 节的前置条件执行。fit/validate/promote 均为离线处理，validate 不启动运动。

init 生成第 2 节的完整键集合，状态 draft，未测物理值为 null。验收要求和待试参数由操作者先填入 draft 配置；fit 只更新对应测量字段并输出独立候选文件。promote 要求全部阶段验收通过后设置 verified。

### 1.3 数据与报告格式

JSONL 每行包含 `stage、run_id、sample_id、captured_at_ns、payload`，时间由当前进程 monotonic_ns 产生。每次实验第一条 payload 使用 `record_type="metadata"`，记录设备型号、固件、供电、指垫、负载和操作者；样本 record_type="sample"。各阶段其余 payload 字段见对应测量章节。

拟合样本和独立验证样本的 sample_id 不重叠，保存原始量和换算后物理量。报告包含 `profile_id、parameter_sha256、operator、operator_reviewed、stages、overall_pass`；stages 按八个阶段映射，每项含 input_sha256、fit_sample_ids、validation_sample_ids、checks、passed。每个 check 含 name、field_path、measured、limit、comparison（<=/>=/==/all）、passed、evidence_type（physical/mock/offline）、evidence_refs。

parameter_sha256 对 profile 除 status、verification 外全部字段做排序键、UTF-8、紧凑 JSON 序列化后求 SHA256。verification 保存报告路径与哈希；报告整体审核通过后才能 promote。记录实际测量值，不为通过验收而自动放宽 limit。

## 2. 配置字段字典

所有表中字段均为必需键。`[5]` 按 JOINT_NAMES，`[6]` 按 MOTOR_NAMES；`[5,2]` 每行为 [lower,upper]，`[2,3]` 的两行分别为 XYZ 最小/最大值。实机未知参数在 draft 中为 null，不能由代码补猜测值。

目标在固定 yaw_offset_deg 下的最大闭合轴宽度，可由 object_envelope_m 保守计算：`abs(cos(beta))*length+abs(sin(beta))*width`，beta 转为 rad。preopen_pct 的 gap 须大于该宽度及测量净余量；实际值在抓取试验中确定，不按每颗目标动态修改。

TCP、gap 和 angle 表的开度覆盖区间必须包含 empty_closed_pct、接触区间对应开度、preopen_pct 与 release_pct。接触开度必须大于 empty_closed_pct+empty_tol_pct。

三张表的 gripper_pct 均在 [0,100] 且严格递增；gap_m 非负并严格递增；angle_deg 可递增或递减，但方向在全表一致。标定表共同覆盖区间外的开度不可使用。

## 3. 测量顺序与采集条件

顺序为 motor→joints→tool→workcell→timing→motion→grasp→pick_place。更换零位、指垫、框位置或关键运动参数后，重新验证受影响的后续阶段。

标定前固定基座，确认独立断电急停可用。卸力时托住机械臂。motor 阶段允许单电机配置与卸力手动读数；joints/tool/workcell 阶段使用受限低速点动或手动夹具；timing 阶段先静止读写；motion 使用空场短路径；grasp/pick_place 使用已验证区域与测试物。

capture 的实机模式逐阶段检查前置参数及报告。全部采集、点动、规划和回放顺序执行；拟合与验证离线进行。每阶段仅允许规定动作范围，不自动搜索机械硬端点或运行未校验路径。

## 4. motor：身份、物理量和夹爪百分比

### 4.1 原始记录与准备

payload：`raw_position[6]、raw_velocity[6]、raw_current[6]、reference_angle_deg[6]或null、reference_current_ma[6]或null、sample_start_ns、sample_end_ns、torque_enabled、motion_label`。设备上报的符号位先按型号/固件解码，再进行数值换算。命令记录保存 request 和结果，不能只保留成功数据。

1. 对照 ID 1～6 与实体关节，必要时只连接一个舵机配置 ID；读取固件与型号。
2. 核对串口、供电、波特率；保留官方 LeRobot 校准原始文件和 SHA256。
3. 按官方流程做 homing 与范围采集；手动缓慢经过可达范围，避免顶死。不要重复在本项目里再加一次官方 homing_offset。
4. 特别记录 wrist_roll 的实际线缆安全范围。官方校准中把 wrist_roll 记为 0～4095 不代表应用可以绕满一圈。

### 4.2 关节读数的严格换算

本机 LeRobot 的 DEGREES 归一化使用官方 calibration 中 `mid=(range_min+range_max)/2` 和 `resolution-1`：

```python
q_bus_deg = (raw_position_after_homing - mid) * 360.0 / (resolution - 1)
q_urdf_deg = joints.sign * q_bus_deg + joints.zero_offset_deg
q_bus_command = (q_urdf_command - joints.zero_offset_deg) / joints.sign
raw_command = round(q_bus_command * (resolution - 1) / 360.0 + mid)
```

生产 C 可以调用已验证的 SDK DEGREES 转换，再做 sign/offset；也可使用上述原始公式，二选一，不重复归一化。整数取整策略必须固定并用往返测试证明误差不超过半个/一个编码步长的实际实现界限。量化误差也计入限位余量。

### 4.3 电流和速度单位

`current_ma=(decoded_raw_current-current_zero_raw)*current_ma_per_raw`；控制阈值比较其绝对值。current_ma_per_raw 先根据当前型号/固件的厂商资料确定，用可靠参考测量验证合理性。测板上整机供电电流不能直接当某个舵机的电枢电流来拟合“夹持力”；无法可靠验证时记录限制，不伪造 mA/力映射。

速度先按厂商比例转换，关节再乘 joints.sign。用多组低速正反向运动的连续位置差分中位数，与速度读数对照方向和量级。禁止把 Present_Load 当 Present_Current，或把寄存器整数原样填进带 mA/deg_s 名称的接口。

### 4.4 夹爪开闭两端

托住手臂，移走物体，在低速受限条件下记录不持续挤压硬端点的安全闭合读数 closed_raw 和安全张开读数 open_raw。重复至少 5 次，检查迟滞和方向：

```python
g = 100 * (raw_position - closed_raw) / (open_raw - closed_raw)
raw = closed_raw + g / 100 * (open_raw - closed_raw)
```

open_raw 不必大于 closed_raw。分母为 0 禁止使用。超出范围的观测属于异常而不是先裁剪成 0/100 后掩盖故障。夹爪速度用 `raw_count_speed * 100/(open_raw-closed_raw)` 转成 %/s，raw_count_speed 由已换算的轴角速度换回对应编码计数/秒。

验收：ID/方向逐项正确；度数/百分比指令往返正确；电流与速度单位有出处和验证数据；motor 校准文件与当前 EEPROM/homing 状态匹配。

## 5. joints：方向、零位、行程和外部 FK 验证

payload：`q_bus_deg[5]、q_reference_deg[5]、measured_tcp_position_m[3]或null、measured_tool_axes[3,3]或null、fixture_id、load_label、approach_direction`。参考角必须来自几何夹具、量角/倾角测量或外部标记测量，不能把同一个 FK 输出当真值。

1. 按 URDF link/joint 的 origin 和 axis 确认每关节正方向。固定其他关节，手动或很小点动，至少取三个不同角度并覆盖正反方向。
2. 对每关节试 sign=+1/-1，拟合 `q_reference = sign*q_bus + offset`。选择残差较小且符合轴定义的方向，offset 取相应残差均值/稳健估计。
3. 参考姿态若是连杆绝对倾角，要先按 URDF 固定变换和父关节姿态换算为该关节角，不能直接赋给 q_reference。
4. 在安全机械范围内缓慢记录下限、上限；转换到 URDF 坐标后，填 measured_limits_deg。线缆、支架、桌面限制填 application_limits_deg。
5. 从端点测量误差、编码量化和运行停止余量确定 margin_deg，再计算有效交集。B/C 共用同一计算结果。
6. 用至少 10 个未参与拟合的不同构型，含工作区近/远、左/右和不同腕姿，检查外部测得末端/工具参考点与 FK。必要时先用可测的刚性工具标记点，随后在 tool 阶段验证真实 TCP。

验收：方向一致，固定角度偏差和正反向迟滞在预算内，所有验证构型有效；误差随姿态变化明显时排查装配/连杆/模型，检查运动学模型与安装几何。仅用肉眼手摆一次顶抓不能完成本阶段。

## 6. tool：工具坐标轴、TCP 随开度变化与有效开口

### 6.1 器材和采样

使用尺寸已知、不会明显压缩的量块/圆柱、固定定位尖点或标记夹具、游标卡尺；测量精度须优于 acceptance.max_position_error_m 的预期分配。payload：`gripper_pct、q_urdf_deg[5]、tcp_reference_B_m[3]、T_B_TCP_reference[4,4]或null、gap_m、gripper_reference_angle_deg、fixture_id`。

确定实际夹持深度和指垫接触带，在每个使用开度采样至少 3 个不同机械臂姿态；开度至少覆盖闭合附近、中间、预张开、释放范围，通常 5 个以上更便于检查非线性。不要把所有参考点都放在一条直线上或只绕单一轴转动。

### 6.2 固定开度的 TCP 平移

已知独立参考中心 p_B_ref 时，每个样本用 FK 得到 `T_B_E=[R_i,t_i]`，计算 `p_E_TCP_i=R_i.T@(p_B_ref-t_i)`，同一开度稳健平均得到 xyz_m。

若使用未知但固定的 pivot 点，通过多个方向触及同一夹具中心，可解线性最小二乘：`R_i*p_E_TCP - p_B_pivot = -t_i`。需报告矩阵秩/条件数；姿态变化不足时拒绝拟合。夹持中心无法直接触及尖点时，用已知几何偏移的夹具把量块中心换算到接触中心，必须记录该偏移。

按开度得到 translation_samples；只分段线性插值平移，不外插。用未采样的中间开度做独立验证，把插值误差计入 tool.position_error_bound_m。

### 6.3 工具轴旋转

用已知方向的夹具/标记板测量 TCP +X（闭合代表方向）、+Z（接近方向），单位化并正交化，+Y=+Z×+X，得到 R_B_TCP_ref。每个姿态计算 `R_E_TCP_i=R_B_E_i.T@R_B_TCP_ref_i`；对矩阵和做 SVD 投影到 SO(3)，确保 det=+1，作为 rotation_e_tcp。

旋转定义固定在工具主体，不能把活动指转角作为 TCP 坐标轴整体旋转。用至少三个不同腕姿验证实际接近方向/闭合方向，不能只依赖“看起来朝下”。

### 6.4 gap_table 和 angle_table

每个样本开度用卡尺/量块测量预定接触带内表面间距 gap_m；同一开度正反方向各重复至少 3 次，拟合严格单调 gap_table。某段非单调、指垫有过大迟滞或接触带变化时，缩小使用范围或重设计指垫，不强行排序 gap 数据消除物理问题。

测量活动指相对固定夹爪 link 的实际转角，换算成 URDF gripper 关节角后写 angle_table；它服务于碰撞 FK，与五姿态关节 IK 分开。使用经过验证的单调分段线性插值。

验收：独立 TCP 中点、轴向和开口测量通过；预张/接触/释放的全部开度在两张表与 TCP 表覆盖范围的交集中。不得把常数旋转、关节零位、相机 yaw 偏移合并成第二个隐含修正。

## 7. workcell：固定几何、抓取域与配置放置位姿

payload：`entity_id、point_B_m[3]、q_urdf_deg[5]或null、gripper_pct或null、measurement_method、reference_image`。本阶段另保存各处测量精度与夹具编号。

1. 按 URDF 定义在实体基座上标出 +X/+Y，确认 +Z 竖直向上。在桌面至少测 9 个网格点，填 table_z_m 与最大高度偏离 table_flatness_m。桌面倾斜造成竖直路径净距不足时先调整安装。
2. 测量框壁、支架和固定夹具的外边界，生成 workspace.obstacles。用多个 AABB 表示容器的壁和底，内部留作放置空间。
3. 依据网格和实物构造 link_capsules，覆盖舵机、打印件、螺丝、活动指和指垫。活动指的位置按 angle_table 更新。人工核对几何覆盖及 ignore_self_pairs 的每个接触豁免。
4. 用已确定的 grasp.yaw_offset_deg，在目标位置、yaw 和接触开度范围上扫描完整接近—抓取—提起路径，确定 target_bounds_m 与 tcp_bounds_m。保存扫描原始结果供视觉定义可抓取条件。视觉下发时已经满足这些条件；扫描与配置更新在标定阶段完成。
5. 示教 home_joints_deg 和有序 safe_waypoints_deg，空载低速验证段间路线，再带规定测试负载验证。每段检查连杆与持物包络，不只检查 TCP 高度。
6. 测各放置位置，填写 places[place_id].position 与 yaw_deg。position 是释放时物体中心，需要根据支承面高度、物体高度和允许释放落差确定；yaw 按基座 +X 测量长轴角度。
7. 对每个 place_id 验证完整到达、下降、松爪和撤离路线，包含实际接触开度变化。APPROACH/TRANSFER 的竖直偏移使用 approach_height_m；抓取提起用 lift_height_m；释放撤离用 retreat_height_m。

### 7.1 误差预算

用已知中心与长轴的标定物，核对视觉下发位置/角度与独立基座测量，填写 grasp.target_position_error_bound_m 与 grasp.target_yaw_error_bound_deg。该结果用于定位预算，控制不进行每次视觉查询。

目标包络使用 grasp.object_envelope_m；再按目标中心误差、目标角度造成的外缘位移、工具误差、运动模型/负载误差和 object_shift_bound_m 做膨胀。collision.clearance_m 是膨胀后仍须保持的最小净距。

相邻轨迹节点按 max_joint_substep_deg 加密；用关节角增量与点到关节轴最大距离估计节点间扫掠误差，并加入余量。减小采样步长检查结果是否稳定。几何净距不足时调整布置或允许工作域。

### 7.2 放置点录入与验证

优先用独立尺具/定位板测出物体中心和长轴方向，也可使用已验证 TCP 的夹具示教。示教记录的是 TCP 时，按姿态文档的 T_TCP_O 换算成物体中心后写配置。

为每个 place_id 至少选三个不同抓取位置和多个实际接触开度完成实物试放，测量释放后物体中心与长轴误差。误差若随抓取位置变化，排查运动学/TCP；误差若随闭合程度变化，检查 TCP 插值与闭合位移界。配置中的位置和角度以同一基座定义保存，读入后生成 PlacePose。

## 8. timing：单线程调用的读写与停止时限

payload：`tick_index、deadline_ns、read_start_ns、read_end_ns、write_start_ns、write_end_ns、feedback_sequence、checkpoint_ns、stop_condition_ns或null、last_trajectory_write_ns或null、hold_submitted_ns或null、mechanically_still_ns或null、fault_injection`。

1. 在静止姿态下完整读回并提交保持目标，至少记录 1000 个 tick，统计读写的最大值和 P50/P95/P99。随后运行实际同步规划和回放路径，测量计算与 I/O 用时。
2. 用 Mock 注入通信错误，并在可控静止状态测量设备超时行为。read_timeout_s/write_timeout_s 限制整次方法，不因内部寄存器/电机数量成倍增加；核对 SDK 内部是否重新设置超时。
3. max_feedback_span_s 依据整次读回跨度确定；max_feedback_age_s 从 sample_start_ns 计算，不能只看读取结束时间。
4. 设置 should_stop 为按当前 monotonic 时间判断的测试回调；在规划、节点等待、运动、闭爪、到位等待各阶段触发，测从条件成立到停止提交轨迹/完成保持提交的延迟。测试回调本身不阻塞，不引入执行任务。
5. 测量单次底层 IK 调用的最长耗时，计入 planning_poll_s 与接受的停止延迟。规划检查点不能中断正在执行的底层调用；超出要求时需减少每次计算量或调整求解器调用方式。
6. stop_poll_s 控制 sleep 分片，取值不大于一个 tick；max_tick_lateness_s 小于一个 tick。超出迟到阈值必须停止，不补发积压节点。
7. 以外部录像/位置记录区分软件停止与机械实际静止。通信失败时记录保持未提交，不能将返回错误视作已经物理静止。

验收：读写时限有效，正常周期可满足预算，各检查点的停止延迟满足 acceptance.max_stop_latency_s，函数返回后没有继续执行的循环。

## 9. motion：速度、跟踪与到位

payload：`trajectory_id、segment、command_deg[5]、feedback_deg[5]、speed_deg_s[5]、current_ma[5]、tcp_reference_B_m[3]或null、time_ns、gripper_pct、load_label、stop_reason或null`。

1. 在已标定空场从低速单关节短路径开始，逐步验证多关节路径。首次测试值由实机操作者根据设备允许范围设置，不能把示例值作为安全结论。
2. 对同一路径测试逐步增加的速度与加速度组合，每组正反方向重复；记录跟踪误差、振动、电流和到位时间。超出测试边界即停止。
3. 在实际夹持方向下加规定测试负载，覆盖远伸和不同运动方向。max_velocity_deg_s/max_acceleration_deg_s2 取通过范围内留有余量的值；TCP 速度/加速度同时按 FK 和外部测量验证。
4. 设置 max_command_step_deg 不大于 max_velocity_deg_s/FPS；执行器仍检查实际差分速度与加速度。低速不能替代碰撞校验。
5. 分关节测量正常位置滞后、噪声和负载误差，确定 following_error_deg 与 dwell；hard 阈值依据可接受几何偏差和机构限制确定。持续阈值不能大到掩盖卡阻。
6. 用静止噪声和重复到位数据选 settle_position_tol_deg、settle_velocity_tol_deg_s、settle_dwell_s 与 settle_timeout_s。Mock 中验证“停住但未到目标”必须失败。
7. 实测段起点偏差对路径的影响，确定 start_position_tol_deg；超过它时重新规划到同一目标或返回错误。
8. 合法关节 q 经 FK 构造数值测试目标，另用实际抓取域进行 IK 扫描，记录残差/耗时/失败原因。选择 ik 的容差、权重、迭代与停滞参数；数值容差须严于真实总定位误差预算。

验收：空载与测试负载下的定位、跟踪、到位与节拍通过；独立工具位姿误差满足 acceptance。规划与运动期间的反馈检查均由同步调用执行。

## 10. grasp：固定抓取参数与草莓接触试验

### 10.1 数据记录

使用最终供电、装配和指垫，准备规则假果、量块，以及覆盖允许尺寸和成熟度的真实草莓。

payload：`trial_id、object_id、dimensions_reference_m[3]、maturity_label、pad_id、target_center_B_m[3]、target_yaw_deg、yaw_offset_deg、gripper_pct、gripper_current_ma、command_pct、time_ns、contact_label、actual_lift_result、actual_release_result、damage_label、damage_observe_minutes、image_refs`。时序样本中尚未产生的结果为 null，试验结束后保存 trial_summary。

人工观察和影像用于标定验收，不成为运行期视觉通信步骤。

### 10.2 固定开度与接触阈值

1. 测量适用草莓最大长/宽/高，写 object_envelope_m；按固定 yaw_offset_deg 计算闭合轴宽度，并以量块与真果确认实际接触带。
2. 根据 gap_table 选择覆盖该宽度且有适当净余量的 preopen_pct；验证接近时指垫不触碰邻物或桌面。选择能稳定释放且不碰固定环境的 release_pct。
3. 空爪在预定速度下开合至少 20 次，完整记录启动、摩擦、空闭合端的电流与开度，确定 empty_closed_pct、empty_tol_pct 及开合超时。
4. 用量块/假果初测接触开口，再用草莓低速小步闭合。记录首次接触的实际 gap 与电流，将经过验证的接触 gap 最小/最大值及测量余量写入 contact_gap_range_m。该区间须与空闭合端可区分。
5. 根据数据选择 window_samples、contact_current_ma、contact_dwell_s。把滤波、连续确认、读写和一个 tick 的延迟乘 close_speed_pct_s，估算额外闭合量，再用 gap_table 换算压缩距离。超出允许压缩量时降低速度或检测延迟。
6. hard_current_ma 比较未滤波电流，结合设备限制与真实草莓试验设置。若正常运动和接触电流无法可靠区分，则改进指垫或缩小适用范围后重测。
7. 接触判据成立即保持实际开度；设置 hold_dwell_s 检查开度与电流稳定性。测量持物期间的正常开度漂移，确定 slip_opening_change_pct；其作用是异常提示。
8. 张开到 release_pct 后，根据果实脱离行为确定 release_dwell_s；采用独立观察验证，正常代码只检查开度/速度及等待时间。

接触、预张开和释放的全部开度须落在 TCP/gap/angle 表共同覆盖区间内；超出表范围则补测，不能外插。

### 10.3 抓取偏移与高度

1. 用目标几何中心作为基准选定指垫接触带，测量并试验 center_offset_object_m；偏移写在物体坐标系中。
2. 在标定实验中确定一个可用的 yaw_offset_deg，验证该方向下的空间、接触稳定性和允许目标域。运行期固定使用这个值。
3. 在多个尺寸、目标位置和物体 yaw 下，测闭合前后物体中心移动，最大值加测量余量写 object_shift_bound_m。
4. 测 approach_height_m、lift_height_m 和 retreat_height_m，使完整连杆/工具/持物包络脱离桌面和固定障碍。高度沿基座 +Z 定义。
5. 固定参数后测试不同目标位置到各配置放置点的搬运和松爪，记录掉落、位姿误差和损伤。需要改变指垫/偏移/速度时，重新验证受影响阶段。

## 11. pick_place：完整同步调用验收

payload：`trial_id、profile_parameter_sha256、target_position_m[3]、target_yaw_deg、grade、place_id、start_ns、end_ns、software_status、software_stage、holding、recovery_required、actual_success、actual_drop、actual_place_position_m[3]或null、actual_place_yaw_deg或null、damage_label、damage_observe_minutes、image_refs`。

用未参与调参的样本完成不少于 acceptance.min_grasp_trials 的独立试验；覆盖允许抓取位置/方向、实际接触开度与全部 place_id。视觉下发一次目标后运行一次完整同步调用，记录软件返回结果并独立观察实物结果。

分别统计：

- 软件完成率：返回 SUCCESS 次数 / 开始 DESCEND 的次数。
- 实际成功率：物体实际抓起并放到配置位置的次数 / 开始 DESCEND 的次数。
- 掉落率：非预期掉落的次数 / 开始 DESCEND 的次数。
- 损伤率：按规定时间完成观察的果实中损伤数 / 已完整观察果实数；另列观察缺失数。
- 放置中心/长轴误差、单次耗时、反馈跨度、软件停止及机械静止耗时。

软件返回与实际结果不一致时保留误差案例，不自动将电流正常等同于物体实际成功。acceptance.min_grasp_success_rate 针对实际成功率。

故障试验覆盖错误输入格式、缺失 place_id、IK 不收敛、轨迹越限、抓空、开合超时、反馈过期、通信失败和 should_stop。使用 Mock 的项目明确标注，真实夹持与损伤验收使用实物数据。

## 12. 与运行代码共用的计算与验证

标定工具与生产代码共同调用以下函数；签名和配置字段保持一致：

```python

def urdf_deg_to_bus_deg(q_urdf_deg, sign, zero_offset_deg): ...
def raw_to_gripper_pct(raw, closed_raw, open_raw): ...
def gripper_pct_to_raw(pct, closed_raw, open_raw): ...
def tool_transform(gripper_pct, tool_params): ...
def gripper_pct_to_gap(gripper_pct, gap_table): ...
def gripper_pct_to_angle_deg(gripper_pct, angle_table): ...
def effective_joint_limits(urdf_limits_deg, joints_params): ...
```

正常采集使用 MotorController.get_feedback；原始采集通过同一驱动的校准适配层读取 SDK 原始数值（normalize=False），保存实际采样起止时间。运动与抓取试验调用实际 trajectory/executor/ArmController，不在标定工具中另写回放算法。

必要离线检查：

1. 字段、shape、非有限值、未测参数、资源哈希和配置模式校验。
2. 正反方向的关节与夹爪映射往返；open_raw<closed_raw 正确处理；分母为零失败。
3. URDF rad→deg 只发生一次，有效限位空交集失败。
4. TCP/gap/angle 表端点、中点、非单调数据、范围外开度与插值误差。
5. 配置 places 的位置/角度直接转换为 PlacePose，品级不改变所选 place_id。
