# 机械臂抓取—放置模块技术文档

> 本文规定 SO-ARM101 抓取—放置功能的实现行为。数据类型见 [公共接口](../configs/common_interface.py)，空间数学见 [顶抓姿态构造](顶抓姿态构造与R_top_down标定.md)，配置字段与测量方法见 [标定指南](真机参数测量与标定指南.md)。docs 与 README 冲突时以 docs 为准。
> 公共接口已有类型声明；运动控制、配置加载与标定工具按本文实现。示例数值不作为实机标定值。

## 一、功能与调用方式

视觉负责确定抓取目标。视觉下发 `VisionInterface` 即表示目标已经满足当前抓取配置的可抓取条件，包括位置、方向、尺寸、接近空间和周围物体间距。

抓取—放置功能接收这一个目标，按照配置完成接近、下降、闭爪、抬升、搬运、放置、松爪和撤回，返回本次执行结果。放置位置与角度来自 `profile.json` 的 `places`，通过 place_id 引用。

```python
result = arm.grasp_and_place(target, place_id="default")
```

这是单线程、同步、阻塞调用。视觉通过直接调用该入口下发目标；调用返回后才进入下一次视觉检测和抓取。一次调用中目标保持不变，控制不向视觉查询数据。机械臂的规划、串口读写、反馈监控和动作编排均在当前调用线程顺序执行。

### 1.1 职责

| 模块 | 职责 |
|---|---|
| 视觉 | 确定可抓取目标，输出基座系目标中心、长轴角度和品级 |
| 运动控制 | 对指定目标计算抓取位姿、FK/IK、轨迹规划与执行校验、动作编排、反馈监控、停止处理 |
| 电机驱动 | 物理量换算、零位和方向映射、最终指令限位、串口读写、硬件状态反馈 |

目标选择以视觉下发结果为准。控制保留关节限位、IK 残差、轨迹连续性和固定障碍碰撞检查；这些检查用于验证实际执行指令，失败时返回执行错误，不选择其他目标或自行更改目标位置、角度。

### 1.2 工作条件

基座与桌面固定，基座 +Z 竖直向上；目标在动作期间静止且单层摆放；抓取区域及搬运通道满足已标定的净距；放置区域有容纳当前目标的空间。视觉使用同一套抓取参数与工作区标定结果确定目标。

实例接受调用时，机械臂已连接、空爪且处于无碰撞静止状态。调用过程中禁止重入。每次调用只完成一个抓取—放置动作，不内置目标重选、失败重试或品级到放置点的映射。

## 三、坐标与数据语义

### 3.1 固定约定

- `B=base_link`：右手基座坐标系，位置单位 m。
- `E=gripper_frame_link`：URDF 末端参考 link。
- `TCP`：指垫接触区域中心；+X 为闭合方向的固定代表方向，+Z 为接近方向，+Y 由右手规则确定。
- `T_A_B` 将 B 系坐标转换至 A 系；齐次矩阵平移列单位 m。
- 五姿态关节按 `JOINT_NAMES`，对应 ID 1～5；夹爪为 ID 6。
- 接口关节角为 URDF 坐标下的 deg，速度 deg/s，电流 mA；进入运动学内部时转换为 rad。

### 3.2 视觉数据

`VisionInterface.position` 是目标三维几何中心，已经在基座系中；抓取点由控制使用标定偏移从该中心计算。相机坐标转换由视觉完成。

`yaw_deg` 是目标水平长轴相对基座 +X 的角度，绕 +Z 按右手规则为正。长轴不区分头尾，归一化至 `[-90,90)`：`wrap180(a)=(a+90)%180-90`。它描述物体方向，不是 wrist_roll 关节角。

`grade` 是记录用元数据，不参与本函数的抓取目标或放置位姿选择。入口检查数组 shape `(3,)`、float64、有限值、角度范围和字段类型，然后复制 position 作为本次调用的固定输入；数据类冻结不等于 ndarray 内存只读。

### 3.3 中心到抓取 TCP

目标 O 系以 position 为原点，+X 沿目标长轴代表方向，+Z 与基座 +Z 平行。固定抓取偏移与闭合方向偏移从配置读取：

```python
p_grasp = target.position + rz_deg(target.yaw_deg) @ params.grasp.center_offset_object_m
spin_grasp_deg = target.yaw_deg + params.grasp.yaw_offset_deg
T_B_TCP_grasp = top_down_pose(p_grasp, spin_grasp_deg)
T_B_E_grasp = T_B_TCP_grasp @ inverse(tool_transform(gripper_pct, params.tool))
```

`grasp.yaw_offset_deg` 是已标定的夹爪闭合方向相对物体长轴的固定角度。控制使用这个唯一姿态规则，不搜索其他夹持方向。

单动指夹爪的 TCP 随开度变化，使用 `tool.translation_samples` 插值。闭爪时五关节保持，实际闭合后的 g 用于更新 TCP 与名义持物变换。闭合引起的物体位移用 `grasp.object_shift_bound_m` 纳入误差包络。

### 3.4 配置放置位姿

`params.places[place_id]` 加载为 `PlacePose`：position 为释放时物体中心，yaw_deg 为释放时物体长轴相对基座 +X 的角度。两个值都必须在配置中明确给出。未知 place_id 返回 CONFIG_INVALID，臂不动。

闭爪后以实测关节角和开度建立名义关系：

```python
T_TCP_O = inverse(FK_TCP(q_close, g_close)) @ T_B_O_grasp
T_B_TCP_place = T_B_O_place @ inverse(T_TCP_O)
T_B_E_place = T_B_TCP_place @ inverse(tool_transform(g_close, params.tool))
```

`T_B_O_grasp` 的旋转是 `rz_deg(target.yaw_deg)`，位置是目标中心；`T_B_O_place` 的旋转和位置来自 PlacePose。根据此关系计算实际放置 TCP，不能直接将配置中的物体中心作为 TCP。模型假设夹持期间物体相对夹爪不发生超过标定误差界的滑移。

## 四、公开接口

### 4.1 机械臂入口

```python
class ArmController:
    def __init__(self, motor: MotorController, params: MotionParams,
                 should_stop: Callable[[], bool] | None = None): ...
    def grasp_and_place(self, target: VisionInterface,
                        place_id: str = "default") -> GraspResult: ...
    def move_joints(self, q_target_deg: FloatArray,
                    min_duration_s: float | None = None) -> None: ...
    def move_cartesian_top_down(self, tcp_xyz: FloatArray, tcp_yaw_deg: float,
                               min_duration_s: float | None = None) -> None: ...
    def open_gripper(self) -> None: ...
    def close_gripper(self) -> HoldingState: ...
    def wait_settled(self, target_deg: FloatArray, timeout_s: float) -> bool: ...
    def reset_fault(self) -> None: ...
```

类型从 common_interface 导入；MotionParams 来自 motion_params，Callable 来自 typing。should_stop 是可选的快速、无阻塞同步检查函数，缺省返回 False；它不执行视觉检测或串口读写。控制在规划检查点和每个动作 tick 调用它，返回 True 时停止。KeyboardInterrupt 进入同一停止路径。

公开原语用于标定和调试，也通过同一校验与同步执行器。`move_cartesian_top_down` 参数明确为 TCP；只执行当前 TCP 到目标的竖直直线，要求 XY 及姿态在容差内一致。需要横向接近或改变朝向时使用已校验的关节段。原语失败抛带 GraspStatus 的内部 MotionError，技能入口转换为 GraspResult。

### 4.2 电机协议

| 方法 | 语义 |
|---|---|
| `send_action(joints_deg, gripper_pct)` | 校验后单次提交，受写超时约束，不等待到位 |
| `get_feedback()` | 受总读时限约束，完整返回六电机的已换算反馈 |
| `hold_current()` | 有界地读一次并写一次相同五关节角与夹爪开度，返回所用反馈 |

JointFeedback 的 angles_deg、speeds_deg_s、currents_ma 都是 `(5,)`。夹爪使用 gripper_pct、gripper_speed_pct_s、gripper_current_ma；0%=标定闭合端，100%=标定张开端。

C 完成方向和零位转换：`q_urdf = joints.sign*q_bus_deg+joints.zero_offset_deg`，B 不重复补偿。电流和速度字段须为物理量。采样带 sample_start_ns、sample_end_ns 和递增 sequence，时间来自本机 monotonic_ns。

整条参数/限位校验在写入前完成；越限抛 MotorLimitError，不静默裁剪。读写超时、部分读回或部分写入抛 MotorCommunicationError；设备未就绪或报告硬件故障抛 MotorStateError。失败时不返回缓存数据，不宣称总线多电机写入具有物理事务原子性。

三个方法均不持有周期循环。运行期 I/O 重试次数为 0，总时限覆盖方法内部全部寄存器访问；实际 SDK 超时行为必须测量。连接和力矩配置由驱动的初始化流程完成，不能隐藏自动回零动作。

### 4.3 返回结果

GraspResult：status、stage、reason、place_id、holding、recovery_required。枚举取值见公共接口源码。

SUCCESS 表示配置要求的轨迹、关节到位、闭爪接触判据、松爪到位与撤回均已完成。holding 是依据电流和开度的状态估计；物体实际落位和损伤率通过实物验收测定，不把驱动反馈称为视觉确认。

运动已开始后发生错误时锁存故障，recovery_required=True；需确认机械臂空爪、静止且现场可继续，再调用 reset_fault。配置/格式/预规划失败且臂未动时可返回 recovery_required=False。同一调用不重试。

## 五、运动学与轨迹生成

### 5.1 有效限位与 IK

逐关节计算：

```python
lower = np.maximum.reduce([urdf_lower, measured_lower, application_lower]) + margin
upper = np.minimum.reduce([urdf_upper, measured_upper, application_upper]) - margin
```

URDF rad 转 deg 一次；实测和应用限制均在 URDF 坐标中表达。空交集禁止使用。wrist_roll 使用实际线缆允许范围。

RobotKinematics 显式传 JOINT_NAMES 与 `gripper_frame_link`，固定 solver 中夹爪自由度；碰撞模型的活动指角度单独由 gripper.angle_table 设置。五关节 IK 不把夹爪开度当额外姿态自由度。

vendor 单次 inverse_kinematics 调用只执行一次 solver.solve(True)。包装器按当前结果继续迭代，受 ik.max_iterations、ik.max_solve_s、停滞判据约束，并在迭代检查点执行停止/反馈检查。位置、接近倾角、TCP yaw 三项误差同时达标才成功，详见姿态文档。权重是优化偏好，不替代残差验收。

整段使用链式 warm-start，检查分支连续性、有效限位与数值有限性。备用初值只改变求解初值，不改变目标位置、角度或抓取方向。求解失败返回 IK_FAILED。

### 5.2 规划表示

一次动作由顺序 MotionSegment 组成。每段含 name、kind（JOINT/CARTESIAN）、time_s `(N,)`、joints_deg `(N,5)`、固定 gripper_pct 和笛卡尔段的 tcp_targets `(N,4,4)`。关节段 tcp_targets 为 None。

每段时间从 0 开始，节点间隔 1/FPS，包含起终点。五次归一化时间律：`s(u)=10u^3-15u^4+6u^5`，u=t/T；首末速度和加速度为零。

关节段由峰值约束确定 T：`v_peak=1.875*abs(delta_q)/T`，`a_peak=(10/sqrt(3))*abs(delta_q)/T^2`；取所有关节所需时间的最大值，再与 min_duration_s 比较并向 tick 向上取整。零位移段直接确认到位。

笛卡尔下降/抬升段位置沿基座 Z 轴直线插值，固定 TCP 姿态；路点逐个 IK，再检查关节及 TCP 速度/加速度并调整时长重新采样。受限关节不对差值盲目取模 360°。

### 5.3 校验范围

开始动作前预规划完整名义路线；包括已标定接触开度区间内的 TCP/持物变化包络。闭爪后根据实际 g 在静止状态更新剩余路径，并在执行前验证。

校验有效限位、相邻关节步长、速度/加速度、FK 路点残差、自碰撞、桌面和配置固定障碍碰撞。工具和持物包络覆盖 grasp.object_envelope_m 及误差余量。视觉已经保证目标接近空间和邻物间距，控制不接收邻物列表。

连杆采用配置中的胶囊体，固定障碍采用 AABB；相邻轨迹节点之间按 collision.max_joint_substep_deg 加密。仅允许规定接触阶段的指垫—目标接触，不豁免连杆/手指碰桌。松爪过程中也检查张开后的工具包络。

## 六、同步执行与动作顺序

### 6.1 节拍与规划检查点

FPS=30。按顺序逐节点提交，不按墙钟直接跳索引。每 tick：等待计划时刻→停止检查→反馈读取与校验→监控上一条已发目标→检查本次实际发送步长/速度/加速度→发送。发送前再次检查停止与超时。

轻微迟到时顺延本段后续时刻，保证两次发送间隔不小于一个 tick；迟到超过 timing.max_tick_lateness_s 则停止。段结束明确发送终点后等待到位。闭爪等耗时不定的状态独立运行；进入下一段重新设置时间起点。

规划在臂静止时同步完成，在每个路点及 IK 迭代之间调用 `planning_checkpoint()`：检查 should_stop；距上次反馈检查达到 timing.planning_poll_s 时读取反馈，检查位置保持偏差、电流和设备状态。单次不可中断的求解调用耗时必须经实测纳入停止延迟，不承诺在该调用内部可抢占。

等待函数分成不大于 timing.stop_poll_s 的 sleep 片段，逐段检查停止。反馈跨度、年龄与 sequence 必须有效。规划、运动、闭爪、到位等待全程使用同一串口所有者，即当前调用线程。

### 6.2 到位与监控

五关节目标误差不超过 motion.settle_position_tol_deg、速度不超过 motion.settle_velocity_tol_deg_s，且持续 motion.settle_dwell_s 才算到位；超过 settle_timeout_s 失败。

跟踪误差超过 following_error_deg 持续 following_error_dwell_s 停止；超过 following_error_hard_deg 立即停止。五关节电流绝对值超过 joints.hard_current_ma 立即停止。反馈与上一条已提交目标比较，避免将新目标的自然滞后误判为故障。

### 6.3 状态表

| 状态 | 动作与完成条件 |
|---|---|
| CHECK | 接收固定目标与 place_id，读反馈，载入放置位姿并预规划、校验整条名义路线 |
| OPEN | 小步张开到 gripper.preopen_pct，开度和速度满足到位条件 |
| APPROACH | 经配置安全中转位移到抓取 TCP 上方 approach_height_m，确认关节到位 |
| DESCEND | 固定姿态竖直下降到抓取 TCP，确认到位 |
| CLOSE | 五关节保持，小步闭合，接触判据通过后保持实际开度 |
| LIFT | 根据实际闭合开度更新 TCP/持物关系和余下路径，竖直提起 lift_height_m |
| TRANSFER | 经配置安全中转位搬运到放置 TCP 上方 approach_height_m |
| LOWER | 固定姿态竖直下降到放置 TCP，确认到位 |
| RELEASE | 小步张开至 gripper.release_pct，开度/速度到位并等待 release_dwell_s |
| RETREAT | 竖直撤离 retreat_height_m，按仍可能附着物体的包络检查离开路径 |
| RETURN | 经安全中转位回到 workspace.home_joints_deg，确认到位 |
| DONE | 返回 SUCCESS |
| FAULT_HOLD | 反馈有效且保持目标提交成功，锁存故障并返回错误 |
| FAULT_UNCONTROLLED | 无法获得可靠反馈或提交保持，锁存故障并返回错误 |

不同路段执行前读取实测起点，超出 start_position_tol_deg 时重新规划到同一目标或返回错误，不直接跳到规划起点。预规划或更新路径期间五关节与夹爪保持已有目标。

### 6.4 停止与返回

停止/异常后停止提交轨迹节点。通信正常时调用 hold_current 一次，捕获并提交固定保持目标；通信失败则返回明确故障，不无限重试。同步函数返回后不继续运行软件监控循环，位置保持依赖已提交的舵机位置目标。

物理急停独立切断舵机供电，考虑失力后的机械臂和物体下落空间。reset_fault 只在确认空爪、静止及设备正常后解除实例锁存，不自动续接动作或移动回零。

## 七、夹爪控制

预张开度 gripper.preopen_pct 与释放开度 release_pct 从配置读取，均覆盖已标定的目标尺寸范围。闭合每 tick 最多减少 close_speed_pct_s/FPS；五关节目标固定。

对最近 gripper.window_samples 的夹爪电流绝对值取均值；连续 contact_dwell_s 超过 contact_current_ma，且 gap(actual_pct) 落在 contact_gap_range_m 内、actual_pct 大于 empty_closed_pct+empty_tol_pct，才判定接触。空闭合端的受阻电流不计为目标接触。

接触成立后使用本次实测开度保持，不继续加压；等待 hold_dwell_s，开度漂移和电流未触发异常后进入抬升。超过 hard_current_ma 立即停止；达到空闭合区仍无有效接触返回 GRASP_MISS，其他无法确定的闭合状态返回 GRASP_UNCERTAIN。闭合总时限为 close_timeout_s。

持物期间监控相对接触保持开度的变化，超过 slip_opening_change_pct 返回 GRIP_SLIP；这是异常指示，不是物体运动的直接测量。松爪采用 open_speed_pct_s，小步到 release_pct；超过 open_timeout_s 或未到位返回 PLACE_FAIL。接触判定、额外等待和损伤指标需以真实草莓实验确定。

## 八、配置和实现验收

配置字段、单位、采样和计算函数以标定指南为准。实机未测参数保持未完成状态，不用猜测值自动填补。使用固定参数完成验收后才用于实机抓取。

实现顺序：公共接口与配置加载→电机物理量映射和 Mock→TCP/FK/IK→轨迹与固定几何→同步执行器→夹爪控制→完整抓取—放置。

必测项：

1. 一次视觉下发对应一次同步调用，原始目标在整个调用内不被改写；place_id 只读取配置，不根据 grade 选择。
2. 输入格式错误、缺失放置配置和越限命令在运动前拒绝。
3. 合法 q→FK→IK→FK 达到残差要求；不可收敛有限时退出；独立测量真实 TCP 精度。
4. 关节/TCP 速度与加速度、直线下降/抬升、固定障碍和张开工具包络校验。
5. Mock 覆盖滞后、过流、空闭合端电流、抓空、开合超时、通信失败、过期反馈和 CPU 迟到。
6. 各动作、sleep 和规划检查点可响应 should_stop；函数返回后无隐藏执行任务。
7. 独立实物试验记录实际成功、掉落、落位误差和损伤，分别与软件返回值对照。
