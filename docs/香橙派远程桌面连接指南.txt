================================================================================
          香橙派 5 (Orange Pi 5) 开机无显示屏直连与远程桌面指南
================================================================================
适用场景：无独立显示屏、无 HDMI 线，通过一根普通网线直连 Linux 笔记本。
默认账号：orangepi
默认密码：orangepi

--------------------------------------------------------------------------------
【第一步：物理接线与开机】
--------------------------------------------------------------------------------
1. 插上网线：一头插在香橙派网口，一头插在笔记本网口。
2. 通电开机：插上 Type-C 供电线。
3. 观察板载指示灯（等待约 15~20 秒）：
   - 右侧红灯：常亮（电源供电正常）
   - 左侧绿灯：规律的双闪心跳模式“咚-咚，停；咚-咚，停”（代表系统启动成功）


--------------------------------------------------------------------------------
【第二步：笔记本终端获取香橙派 IP】
--------------------------------------------------------------------------------
打开你电脑自带的系统终端（Ctrl + Alt + T），运行以下命令查询香橙派 IP：

方法 A（推荐，不受任何代理软件干扰）：
  ip neighbor show dev enp8s0

方法 B（查看笔记本分配出去的租约）：
  cat /var/lib/NetworkManager/dnsmasq-enp8s0.leases

* 记下查出来的 IP 地址（通常是 10.42.0.xx，假设为 10.42.0.78）。


--------------------------------------------------------------------------------
【第三步：SSH 登录香橙派】
--------------------------------------------------------------------------------
在笔记本终端中运行：
  ssh -Y orangepi@10.42.0.78

* 提示输入密码时输入：orangepi
* 注意：-Y 参数开启了 X11 图形穿透，运行 OpenCV 等程序可直接在笔记本上弹窗。


--------------------------------------------------------------------------------
【第四步：在香橙派上启动虚拟桌面服务】
--------------------------------------------------------------------------------
登录进香橙派后，在香橙派终端里直接运行以下命令（已配置好环境，直接复制执行）：

  tigervncserver :1 -geometry 1440x900 -depth 24 -SecurityTypes None -localhost no --I-KNOW-THIS-IS-INSECURE

* 终端打印出 New 'orangepi5:1 (orangepi)' desktop is orangepi5:1 即代表启动成功！
* 说明：分辨率已设定为 1440x900，完美适配笔记本窗口大小。


--------------------------------------------------------------------------------
【第五步：笔记本打开 Remmina 查看图形桌面】
--------------------------------------------------------------------------------
1. 在笔记本应用菜单中搜索并打开「Remmina」。
2. 顶部协议下拉菜单选择：VNC。
3. 连接地址填写：
   10.42.0.xx:5901
   （⚠️ 注意：末尾必须带上端口号 :5901）
4. 密码留空，直接点击【连接】。
5. 进入桌面后，点击 Remmina 界面左侧工具栏的「自适应缩放」图标，体验更佳。


--------------------------------------------------------------------------------
【常用维护技巧】
--------------------------------------------------------------------------------
1. 如果想关闭桌面或修改分辨率重启：
   tigervncserver -kill :1
   tigervncserver :1 -geometry 1920x1080 -depth 24 -SecurityTypes None -localhost no --I-KNOW-THIS-IS-INSECURE

2. 关机命令（在香橙派终端执行）：
   sudo poweroff
