# 手眼标定工程实战落地方案：侧斜视与分拣区专属版（Eye-to-Hand）

针对实际工况确认（**相机侧斜视安装、画面右侧为机械臂、中左侧为分拣抓取区**），本方案对标定点布置、视觉解算与现场防遮挡流程进行针对性优化。

---

## 1. 侧斜视角对标定的工程利好与优化

```
  [Astra Pro 侧斜俯视] (俯角 30°~60°)
         \
          \
           \
     +-----------------------------------------------+
     |  [1] [2]      [3] [4]          | [机械臂底座]  |
     |   (分拣远端)   (分拣近端)       | (画面右侧)    |
     |     [5]垫高点    [6]垫高点      |               |
     +-----------------------------------------------+
     <--------- 中左侧有效分拣工作区 --------->
```

### 1.1 利好 1：侧斜视天然打破了“Z 轴退化”
- 正俯视时桌面各点到相机的 Z 几乎相同；但在**侧斜视**下，桌面上“远端”和“近端”到相机的距离天然存在 $10\text{cm}\sim 30\text{cm}$ 的明显梯度！
- 加上 1~2 个小垫高块（2~4cm），空间在相机系下的 $(X, Y, Z)$ 三轴分布极其充盈，**数学刚性极强，SVD 求解绝对稳定**！

### 1.2 利好 2：标定区域与抓取区域 100% 重合
- 标定靶心直接放置在**中左侧的分拣采摘区**。
- 机器人学黄金法则：**“在哪个区域作业，就在哪个区域标定”**。这样做能把光学畸变和机械臂连杆微小形变的累积误差压缩到最低，确保草莓分拣区达到 $\le 1\sim 2\text{ mm}$ 的极致精度。

### 1.3 利好 3：分时防遮挡天然契合
- 机械臂待命位（Home）在右侧。
- 第一阶段拍照时，机械臂收在右侧，**中左侧的分拣区完全空旷、视野 100% 无遮挡**，相机能极其清晰地一次性锁定全部标记点。

## 2. 侧斜视下的视觉双保险：PnP + 深度图交叉验证

在侧斜视拍摄下，为了确保每个 ArUco 标记的相机系坐标 $P_{cam}$ 绝对准确，程序内置**“几何 PnP + 深度图多像素中值”双重交叉验证**：
1. **主通道（RGB PnP）**：利用 $1280 \times 720$ 高清图提取 4 个亚像素角点，配合已知内参解算标记中心坐标 $(X_c, Y_c, Z_c)_{PnP}$。
2. **校验通道（Depth Aligned）**：读取 Astra Pro 对齐深度图中标记中心 $7\times 7$ 区域的有效深度中值 $Z_{depth}$。
3. **一致性检查**：如果 $|Z_{PnP} - Z_{depth}| < 5\text{mm}$，说明识别极为健康可靠；若反光导致偏差过大，终端自动预警提示微调标记摆放。

## 3. 现场实操极简流水线（3 步走）

### 第一步：贴标（耗时 2 分钟）
- 打印生成的 6 张 $40\text{mm}$ ArUco 标定纸块（带大号编号 1~6）。
- **1、2 号贴在中左侧分拣区远端桌面**；
- **3、4 号贴在中左侧分拣区近端桌面**；
- **5、6 号分别贴在一个 3cm 左右的小盒子/木块表面，放在分拣区中间**。

### 第二步：运行标定程序 (`touch_calibrator.py`)
1. 机械臂停在右侧 Home 位。
2. 执行脚本，相机自动拍下一张高清帧并存为 `calibration_snapshot.jpg`（画面上会自动画出检测到的标记框和 3D 坐标，方便用户直接在屏幕核对）。
3. 终端提示：
   ```text
   [视觉就绪] 成功锁定分拣区 6 个标定点！
   --------------------------------------------------
   [1/6] 请示教机械臂夹爪尖端对准【1 号点】，输入机械臂坐标 X Y Z (mm 或 m，空格分隔):
   ```
4. 依次输入 6 个点的示教器坐标。

### 第三步：自动检验与保存
程序瞬间完成 Umeyama SVD 求解，并自动执行精度验收：
- 逐点计算残差（$e_i = \|P_{base}^{(i)} - (R P_{cam}^{(i)} + t)\|$）。
- 验证是否满足 P3 文档规范（最大误差 $\le 4\text{ mm}$）。
- 自动写入标准格式的 `configs/vision/T_base_camera.json`！
